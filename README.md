# Student Attendance Application

A web-based student record management application built with Python, Flask, and SQLite.

## Features
- Register student records
- Store student information in an SQLite database
- View registered students on a dashboard

## Technologies
- Python
- Flask
- SQLite
- HTML and CSS

## Installation
1. Install Python 3.10 or later.
2. Install dependencies: pip install -r requirements.txt
3. Run the application: python app.py
4. Open http://127.0.0.1:5000 in your browser.

## Project Structure
- app.py - Flask application and routes
- database.py - Database operations
- templates/index.html - Web dashboard
- requirements.txt - Python dependencies

## Note
This project is for learning and demonstration. Do not use real student data without appropriate security and privacy protections.
